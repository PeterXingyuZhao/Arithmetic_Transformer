# Extended-GSM provenance and reuse

The word-problem templates in this directory adapt **GSM8K**, introduced by
**Karl Cobbe and collaborators at OpenAI** in *Training Verifiers to Solve Math
Word Problems* (2021): <https://arxiv.org/abs/2110.14168>.

- Original dataset repository: <https://github.com/openai/grade-school-math>.
- Original license: **MIT**.
- Original notice: **Copyright (c) 2021 OpenAI**.
- Complete original license: [../licenses/GSM8K-MIT.txt](../licenses/GSM8K-MIT.txt).

We retain the upstream MIT notice for the reused question content. This document
does not replace the upstream license or apply it to unrelated contents of the
same files.

## What was changed

Selected GSM8K problems were adapted into parameterized templates and extended
with additional clauses involving quantities or relationships. Reference answers
are recomputed by the generator functions. The current evaluation uses **50
templates** and clause-count settings **k = 1 through 6**. Values and relationships
in the generators include fixed lists; this documentation does not claim that
every value was sampled independently at random.

This modified evaluation set is not the original, unmodified GSM8K test set.

## Files and their contents

| Files | Content and provenance |
| --- | --- |
| `myGSM_test.ipynb` | Current template generators and evaluation code; GSM8K-derived word-problem text. |
| `gsm-test.ipynb` | Earlier GSM8K-derived question generators and evaluation code. |
| `k_1/*.csv` through `k_6/*.csv` | Generated benchmark questions, reference answers, model responses, predictions, and correctness measurements. |
| `question_repo.numbers` | Accompanying question workbook; any GSM8K-derived question text retains the same upstream attribution. |
| `models_k_corrects*.csv`, plots, and `bar_plot.py` | Aggregate evaluation results and plotting code; these are distinct from the original GSM8K questions. |

The CSV fields have different origins:

- **Questions and reference answers:** generated from the adapted benchmark
  templates; preserve the GSM8K attribution and original MIT notice with the
  reused content.
- **Model responses:** generated by the model identified in the file or record;
  these are not original GSM8K answers and are not assigned GSM8K's MIT license
  by this repository.
- **Predictions and correctness:** derived by the evaluation/scoring code.

See [../MODEL_LICENSES.md](../MODEL_LICENSES.md) for model identities and terms,
including provisions that may affect reuse of generated outputs. Do not infer
a blanket permission to use response CSVs for training other models from the
GSM8K license. The root [third-party notices](../THIRD_PARTY_NOTICES.md) identify
the separately reused software.

If distributing this directory separately, include the original GSM8K license
and applicable notices with it, rather than leaving links to missing parent
files.
