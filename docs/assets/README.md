# Figure provenance

The two README images are raster exports of Figure 1 panels from the final manuscript of *Shattered Compositionality: Counterintuitive Learning Dynamics of Transformers for Arithmetic* by Xingyu Zhao, Darsh Sharma, Rheeya Uppaal, and Yiqiao Zhong.

| README asset | Original manuscript asset |
| --- | --- |
| `addition-plain.png` | `Figures/Images/4_operand_addition_plain_temp_0.8.pdf` |
| `addition-reversed.png` | `Figures/Images/4_operand_addition_reverse_temp_0.8.pdf` |

The panels were exported with Poppler (`pdftoppm -singlefile -scale-to 1500 -png`); no curves, axes, labels, or data were changed. The legend in the ordinary-output panel applies to both panels.
